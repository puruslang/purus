# Contributing to Purus Prettier Plugin

Thank you for your interest in contributing!

[日本語版はこちら](https://github.com/puruslang/prettier-plugin/blob/main/CONTRIBUTING-ja.md)

## About

Prettier plugin for formatting Purus code.

## Prerequisites

- [Node.js](https://nodejs.org/) >= 22
- [Git](https://git-scm.com/)

## Getting Started

```sh
git clone https://github.com/puruslang/prettier-plugin.git
cd prettier-plugin
npm install
npm test
```

## Development

| Command | Description |
|---|---|
| `npm test` | Run tests |

## Submitting Pull Requests

1. Fork the repository and create a branch from `main`
2. Make your changes
3. Run tests and ensure they pass
4. Open a PR with a clear description

## Release

Releases are triggered by pushing a `v*` tag (e.g., `v1.1.0`).
